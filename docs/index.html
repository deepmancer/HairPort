HairPort

In-context 3D-Aware Hair Import and Transfer for Images

A. Heidari, A. Alimohammadi, W. Michel Pinto Lira, A. Bar-Lev, and A. Mahdavi-Amiri

Transfer a reference hairstyle onto a source face with 3D-aware pose alignment, realistic bald conversion, and identity-preserving final synthesis.

Project Page Code Citation Dataset Weights Paper coming soon Video coming soon

Why HairPort

Hair transfer that understands viewpoint.

Most image-based hairstyle transfer methods struggle when the source face and reference hairstyle differ in pose, scale, or visible hair coverage. HairPort separates hair removal from transfer, lifts the reference hairstyle into a 3D-aware alignment stage, and then synthesizes the final image from source-aligned evidence.

Results

Robust transfers across identity, style, and viewpoint.

HairPort handles realistic photos, stylized references, large pose gaps, and significant scale differences while preserving the source identity.

Highlights

Built for the failure cases that make hair transfer hard.

01

3D-aware transfer

Reconstructs and re-renders the reference hairstyle from the source viewpoint before final synthesis.

02

Large pose gaps

Designed for transfers where direct 2D warping or local editing loses important hair structure.

03

Identity preservation

Separates bald source generation from hairstyle import so the face remains stable.

04

Bald Converter

Uses FLUX LoRA in-context editing to create realistic bald portraits for transfer conditioning.

05

Baldy dataset

Introduces 6,400 paired bald and original images for training the Bald Converter.

06

Modular code

Exposes stages separately for inspection, debugging, extension, and future component swaps.

Method

From bald source to source-aligned hairstyle evidence.

The pipeline first removes source hair, then aligns the reference hairstyle through a 3D-aware transfer stage, and finally synthesizes the completed transfer.

Bald Converter and Baldy

A dedicated bald-generation stage for cleaner transfer.

The Bald Converter produces realistic bald versions of source portraits using LoRA-based in-context adaptation of FLUX. Baldy provides paired bald/original supervision across diverse identities and conditions.
